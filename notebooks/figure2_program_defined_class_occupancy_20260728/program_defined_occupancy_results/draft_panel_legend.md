Figure 2. Perturbation classes redistribute cells among program-defined developmental states. Each cell was assigned its global dominant cNMF program across all 50 programs. The primary analysis retained cells only when that globally dominant program belonged to the curated program set and matched the observed collection day; cells were not forced into a curated state. For each biological target and each day-specific dominant-program state, adjusted one-versus-rest logistic regression was performed using a target-union carrier indicator and biological sample, pct_counts_mt, log1p(total_counts), log1p(guides_per_cell), log1p(guide_umi_counts), and log1p(n_genes_by_counts) as covariates. Dot color denotes the median stable target-level adjusted log odds ratio in each reviewed regulator class. Dot size denotes the fraction of evaluable targets with FDR < 0.05 in the direction of the class median. Class guides were not pooled before target-level modeling. No target→program differential-effect estimate was used to define or test these states.
