# Methods note

Program-defined states were created from cell-level cNMF usage rather than Leiden clusters. For each cell, the globally highest-usage program among all 50 cNMF programs was identified. A cell entered the primary analysis only when that global dominant program was in the curated primary program list derived from the Hunter/Kyle annotation table and its expected stage matched the cell's observed collection day. Cells whose dominant program was not curated were not reassigned to the best curated program. This makes the primary estimand the relative occupancy of curated program-defined states among cells confidently represented by the curated state space. A sensitivity model compares each curated dominant-program state with all cells collected on the same day.

Target carriage was defined as at least one assigned guide mapping to the reviewed intended_target_name; multiple guides targeting the same gene were collapsed to one target-union indicator. Cells with guides targeting multiple genes contributed to each corresponding target model. Cells carrying both control and real-targeting guides were retained as target carriers and were not considered pure controls. Per-target one-versus-rest logistic models were fitted separately by day with biological sample and approved technical covariates. Benjamini-Hochberg correction was applied within day across target-by-program-state tests. Class summaries were calculated only after target-level modeling.
