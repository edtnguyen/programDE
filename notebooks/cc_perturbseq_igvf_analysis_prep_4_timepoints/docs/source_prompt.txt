For every .tsv.gz file:

- Run gzip integrity validation.
- Confirm it is actually gzip-compressed.
- Confirm it is tab-delimited.
- Confirm there is exactly one header row.
- Check for duplicate column names.
- Check for duplicate primary-key rows where inappropriate.
- Record row count and column count.
- Check for completely empty tables.
- Check for malformed rows.
- Check for unexpected binary or Excel content.
- Record missing-value conventions.
- Confirm gene, guide, element, program, or regulator identifiers are consistent with upstream files.
- Confirm p-value, q-value, effect-size, loading, or correlation columns are within valid ranges where applicable.

Calculate the MD5 checksum from the exact final file that will be uploaded, including the compressed .tsv.gz file rather than the uncompressed source.

Do not reuse a checksum from an earlier version of a file.
