# Methods note

States were fixed before occupancy testing using the existing author-defined mapping of `leiden_res_0.5`. Each biological target was represented by a union indicator equal to one when at least one guide targeting that intended_target_name was assigned. Cells with multiple targeting genes contributed to each corresponding target indicator, as expected under the high-MOI design. Cells carrying both control and targeting guides were treated as target carriers in the primary all-cell marginal model and were flagged in the exported metadata. Pure controls were defined as cells with at least one safe/non-targeting guide and no real-targeting guides and were used for descriptive and strict-control sensitivity analyses. Models were fit separately by day and state using binomial logistic regression. Benjamini-Hochberg adjustment was applied within day across the target-by-state testing family.
